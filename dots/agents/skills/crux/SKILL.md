# Crux

The crux is the most important part of a challenge that can actually be
solved soon. It is usually the only large problem standing between the solution and current state of things
most things around it are noise / decisions that are known.
Decisions must always be explicit never implicit.. so u must always understand and be able to explain the reasoning
behind a decision taken when working toward a problem

Once the crux is named and agreed upon between agent and human, problem solving / coding can begin.
