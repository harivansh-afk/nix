# Deepen

Make the task deeper, not bigger. Keep its scope; raise its standard.

Before rewriting the prompt, answer each of these for the field the task belongs to:

1. What a top professional would do here that the prompt does not ask for.
2. The rawest material they would start from, instead of what has already been digested (summaries, secondhand write-ups, prior conclusions).
3. The specific methods and tools they would use.
4. What, other than the agent or Hari, would show the result is right: a test, a measurement, a primary source, an external check.

Then rewrite the prompt to ask for exactly that, and stop for Hari's go-ahead before doing the task.
